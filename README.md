## 🌟 The Origin Story

I embarked on my coding adventure in 2022, driven by pure curiosity and a relentless desire to master the art of programming. For my first two years, I learned, practiced, and experimented — mostly offline, accumulating hundreds of files in Java, C, C++, Python, HTML, and CSS.

On **October 2nd, 2023**, I made a pivotal decision: to upload all my learning files to GitHub. At that time, I was new to GitHub and repositories, so I simply wanted a safe, permanent place to store my progress.

But growth never stops.

From that day till now (**May 2025**), I've supercharged my skills, built exciting projects, and evolved into a creator with bigger aspirations. Now, I'm committed to making my journey public, sharing every learning, every experiment, and every project — because knowledge multiplies when shared.

## 🚦 How To Explore

**Navigate by Language:**  
Each folder is named after its language. Drill down to find files of each language.

**Run the Code:**  
Most files are standalone and ready-to-run.  
- Java: `javac FileName.java && java FileName`
- C: `gcc file.c -o file && ./file`
- C++: `g++ file.cpp -o file && ./file`
- Python: `python file.py`
- HTML/CSS: Open in your browser

**Tip:**  
Many files have comments explaining concepts and logic. For deeper context, check folder-level READMEs (coming soon).
